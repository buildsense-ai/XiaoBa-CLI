# Human-Friendly Report Contract

## Executive page

Use five compact blocks:

1. Finding: one or two sentences.
2. Envelope status: Incomplete, Complete → Issue, or Complete → Close.
3. Decisive evidence: at most three points.
4. Material gap: one point, or “none material to the decision.”
5. Reviewer recommendation: one sentence.

Include a simple flow:

`Finding → Evidence work → Completeness gate → Issue | Close`

## Evidence pages

Show only decision-relevant views:

- event timeline;
- runtime path;
- hypothesis/evidence matrix;
- provenance flow;
- completeness gates.

Each visual gets one or two sentences. Move detailed paths, hashes, commands, raw tables, and privacy checks to appendices or machine files.

## Visual acceptance

Before delivery, verify every page for:

- readable Chinese fonts;
- no clipped or overlapping text;
- accurate page count;
- clear status and recommendation;
- no unsupported causal language;
- no sensitive content.

A generated file is not accepted merely because it opens. It must be visually inspected.
